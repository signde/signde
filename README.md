# Current Projects

## Several skins for avdvplus/p3i based CoreELEC builds

A collection of skins modified to take advantage of features available in CPM-based CoreELEC builds. Main features include:

- Integrated custom PPI, a fork of TinyPPI originally by jamal2362
- Custom media flag icon sets

See my [Kodi forum thread](https://forum.kodi.tv/showthread.php?tid=388348) for more info.


## Audio and Video Enhancements for Fire TV Cube 3 / Fire TV Stick 4K Max

- Magisk module for audio passthrough in Fire OS
- WIP: Dolby Vision Profile 7 FEL rendering in Fire OS

See my [xda forum thread](https://xdaforums.com/t/mod-magisk-root-fireos-7-8-dolby-dd-dd-and-dts-hd-ma-dts-x-passthrough-module.4804107/) for more info.

## Video information overlay for select Android TV devices

Shows information about currently playing video and audio, plus some device statistics on a small set of Android TV devices.

See my [avsforum thread](https://www.avsforum.com/threads/video-information-overlay-for-select-android-tv-devices.3354271/) for more information.
